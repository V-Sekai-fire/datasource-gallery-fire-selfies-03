# datasource-gallery-fire-selfies-03

One part of a split series of iFire's selfies taken in social VR, built into a static photo gallery.

## What it is for

The photographs are the source, and a static-gallery generator turns them into this repository's pages site.

## Build and run

The gallery workflow runs the thumbsup generator in a container with `config.json` and deploys the result each time the default branch changes.
